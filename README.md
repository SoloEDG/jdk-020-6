# APRON 07

机场机坪调度模拟：分配机位、派遣地勤车辆、编制货运舱单，让每个航班准时离港。

## 安装

```sh
npm install
```

## 本地启动

```sh
npm run dev
```

## Docker 启动

```sh
docker compose up --build
```

浏览器打开 http://localhost:8120 。

## 玩法

- **航班过站**：选择航班 → 分配机位 → 派遣行李/加油/清洁车 → 批准推出。每个机位同时最多占用 2 个服务位。
- **货运舱单**：每班航班带有到港货与离港货。每批货有目的地、重量、相容类别（普货/鲜活/活体/易燃/氧化剂）与收益。
- **配载方案**：为每批离港货指定舱位（前/中/后舱）或拉货。方案需同时满足舱位限重与单件上限、重心包线、危险品同舱/相邻舱隔离，以及装载车起重能力——不能只看总重量。面板实时显示留下的货物与收益变化。
- **共享场地**：到港卸货与离港装货共用机位旁的 4 格临时区与装载车；禁配货不会在临时区相邻堆放。
- **真实装卸**：装载车逐批执行卸机/提走/出库/装机。装到一半修改方案时，已进舱的货必须经真实卸回步骤调整。
- **放行检查**：只有实际货物位置与最终舱单逐批一致，且方案通过全部安全检查，航班才能推出。货运收益随离港结算。
- **存档**：班次可保存到浏览器；重新打开时舱单、临时区、车辆载荷与离港检查逐批核对一致才会读取。
